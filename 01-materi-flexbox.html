Flexbox

01 / Konsep Dasar

Apa itu Flexbox?

Flexbox (Flexible Box Layout) adalah model layout CSS yang dirancang untuk menyusun elemen dalam satu arah — baris (horizontal) atau kolom (vertikal) — beserta pengaturan jarak, urutan, dan ukurannya secara otomatis.

Sebelum flexbox, developer biasa mengatur layout memakai float atau display: inline-block, yang sering merepotkan untuk hal-hal sederhana seperti:

  • Membuat 3 kotak sejajar dengan jarak yang rata otomatis
  • Membuat elemen berada tepat di tengah (vertikal dan horizontal)
  • Membuat elemen menyesuaikan ukuran mengisi ruang kosong yang tersisa
  • Mengubah urutan tampilan elemen tanpa mengubah urutan di HTML

Flexbox menyelesaikan semua itu hanya dengan beberapa baris CSS. Cukup tambahkan display: flex pada elemen pembungkus (parent), maka elemen-elemen di dalamnya otomatis menjadi "flex item" yang bisa diatur.

Ingat: Flexbox itu satu dimensi — fokus mengatur baris ATAU kolom. Untuk layout dua dimensi (baris DAN kolom sekaligus, seperti tabel), CSS punya display: grid, yang akan dibahas terpisah.
02 / Konsep Dasar

Parent dan Child

Flexbox selalu bekerja dengan dua peran: elemen pembungkus dan elemen yang dibungkus.

Flex Container (Parent)

Elemen yang diberi display: flex. Dialah yang "memegang kendali" — mengatur arah, jarak, dan penyelarasan semua anaknya.

Flex Item (Child)

Elemen anak langsung di dalam flex container. Setiap flex item bisa diatur ukuran, urutan, dan posisinya masing-masing.

HTML

<div class="parent">
  <div class="child">Item 1</div>
  <div class="child">Item 2</div>
  <div class="child">Item 3</div>
</div>

CSS

.parent {
  display: flex;   /* ini membuatnya jadi flex container */
}
Penting: display: flex hanya memengaruhi anak langsung. Cucu (anak dari anak) tidak otomatis ikut aturan flexbox, kecuali parent-nya juga diberi display: flex.
03 / Konsep Dasar

Axis & Size

Ini konsep paling penting di flexbox. Semua property container dan item pada dasarnya mengacu pada dua sumbu ini.

IstilahPenjelasan
main axisSumbu utama — arah mengalirnya flex item. Ditentukan oleh flex-direction.
cross axisSumbu tegak lurus terhadap main axis.
main start / main endTitik awal dan akhir di sepanjang main axis.
cross start / cross endTitik awal dan akhir di sepanjang cross axis.
main sizeUkuran item/container diukur sepanjang main axis (lebar, jika arahnya baris).
cross sizeUkuran item/container diukur sepanjang cross axis (tinggi, jika arahnya baris).
Kunci: Saat flex-direction: row → main axis = horizontal, cross axis = vertikal. Saat flex-direction: column → main axis dan cross axis bertukar tempat. Ini yang bikin banyak pemula bingung soal justify-content vs align-items.
